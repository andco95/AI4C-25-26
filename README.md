## Project Overview

This repository contains the code, data processing pipelines, and experiments developed for the AI for Cybersecurity project. The project focuses on leveraging Artificial Intelligence and Machine Learning techniques to solve modern security challenges.

### Key Objectives
- **Detection & Classification:** Implement Machine Learning models to identify Botnet Detection.

## ⚙️ Requirements installation 

### Prerequisites
- Python 3.10 or higher
- Git

### Quickstart

1. **Clone the repository:**
   ```bash
   git clone https://github.com/andco95/AI4C-25-26.git
   cd AI4C-25-26
   ```

2. **Create and activate a virtual environment:**
   - On Linux/macOS:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```

3. **Install dependencies:**
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

## 📊 Dataset

*Briefly describe the dataset used in this project.*

- **Name:** CTU-13-DataseT
- **Description:** The CTU-13 is a dataset of botnet traffic that was captured in the CTU University, Czech Republic, in 2011. The goal of the dataset was to have a large capture of real botnet traffic mixed with normal traffic and background traffic.
